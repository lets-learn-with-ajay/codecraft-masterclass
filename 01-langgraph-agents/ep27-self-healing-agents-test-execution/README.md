## 📌 Summary
Autonomous software engineering loops. Sandboxed execution of agent-generated code using Docker, parsing pytest tracebacks, and self-correcting syntax and logic errors in automated reflection loops.

## 🎯 Key Takeaways
- Execute generated code in ephemeral Docker containers with strict CPU, memory, and network limits
- Feed raw compiler diagnostics and test assertion failures directly into critic revision nodes
- Bounded iteration guards prevent runaway loops on fundamentally unsolvable logic contradictions
