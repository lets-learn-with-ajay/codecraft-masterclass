## 📌 Summary
Building a team of specialized sub-agents (Researcher, Coder, Reviewer) orchestrated by a supervisor agent with dynamic routing and reflection loops.

## 🎯 Key Takeaways
- Supervisor agents route tasks to specialized sub-agents based on dynamic task requirements and conversation context.
- Sub-agents maintain their own local state or operate on shared global state.
- Delegation patterns isolate complex domain tasks into focused prompts and narrow toolsets.
