## 📌 Summary
Series Capstone: Building an autonomous software engineer. Ingesting full GitHub repositories, extracting tree-sitter AST dependency graphs, indexing symbol definitions, and planning multi-file refactors.

## 🎯 Key Takeaways
- Tree-sitter AST parsing extracts precise function signatures, call hierarchies, and import graphs
- Graph indexing allows agents to trace symbol dependencies across dozens of interconnected modules
- The planner agent produces structured, dependency-ordered refactoring execution plans
