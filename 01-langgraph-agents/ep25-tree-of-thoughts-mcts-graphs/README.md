## 📌 Summary
Algorithmic decision exploration. Implementing Tree-of-Thoughts (ToT) and Monte Carlo Tree Search (MCTS) using LangGraph cyclic graphs, automated path evaluation scoring, and backtracking algorithms.

## 🎯 Key Takeaways
- Generates multiple candidate reasoning branches at each step rather than committing to greedy generation
- Evaluator nodes assign quantitative heuristic scores to each trajectory to identify optimal paths
- Backtracking mechanisms prune low-scoring branches and explore promising alternative solutions
