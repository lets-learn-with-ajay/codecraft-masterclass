## 📌 Summary
Scaling beyond flat teams using nested subgraphs, team leads, and isolated team state delegation for complex software projects.

## 🎯 Key Takeaways
- Subgraphs encapsulate entire multi-agent teams as single callable nodes.
- Team leads manage internal consensus before reporting back to the global supervisor.
- Reduces prompt token pollution by scoping team communication locally.
