## 📌 Summary
Implementing cross-conversation memory using semantic vector stores and entity extraction (Mem0/Zep pattern) in LangGraph.

## 🎯 Key Takeaways
- Short-term checkpointers maintain thread state; long-term memory spans across user threads.
- Entity extraction nodes persist user preferences and facts to semantic stores.
- Dynamically injects relevant historical facts into prompt context before LLM generation.
