## 📌 Summary
Consolidating Part 1 into a complete runnable CLI project: reading user input with std::io, parsing integers, validation, structs, enums, loops, and in-memory state management.

## 🎯 Key Takeaways
- std::io::stdin().read_line captures user terminal input into a mutable String buffer
- Combine enums, structs, and match to build clean interactive command loop state machines
- Building a complete end-to-end application cements ownership, borrowing, and type system fundamentals
