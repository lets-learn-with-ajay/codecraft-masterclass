## 📌 Summary
Modeling domain data in Rust. Defining named-field structs, tuple structs, unit structs, associated constructors (Self::new), and methods with &self, &mut self, and self (consuming).

## 🎯 Key Takeaways
- Structs package related fields together into cohesive custom data models with strict type safety
- impl blocks define methods taking &self or &mut self, and associated functions like Self::new
- Field init shorthand and struct update syntax ({ ..other }) make struct construction expressive
