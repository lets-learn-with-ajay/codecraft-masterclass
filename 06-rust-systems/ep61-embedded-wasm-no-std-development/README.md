## 📌 Summary
Compiling Rust for bare-metal microcontrollers and the web. Living without the standard library with #[no_std], panic handlers, embedded-hal, and compiling to high-performance Wasm with wasm-bindgen.

## 🎯 Key Takeaways
- #[no_std] removes dependencies on the OS runtime, targeting bare-metal microcontrollers and embedded chips
- WebAssembly binaries compile down to compact bytecodes that execute at near-native speeds inside browser engines
- wasm-bindgen seamlessly bridges high-level JavaScript objects with low-level Rust linear memory
