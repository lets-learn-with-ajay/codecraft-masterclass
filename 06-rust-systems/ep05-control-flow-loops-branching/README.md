## 📌 Summary
Branching and iteration fundamentals. if/else as expressions in let bindings, infinite loop with break values for polling/retries, conditional while loops, and bounds-check-free for ranges.

## 🎯 Key Takeaways
- if/else is an expression that can assign values to let bindings when all branches evaluate to matching types
- loop can return a computed value directly via break expr, ideal for retries and polling loops
- for item in collection is the safe, bounds-check-free idiomatic pattern for iteration in Rust
