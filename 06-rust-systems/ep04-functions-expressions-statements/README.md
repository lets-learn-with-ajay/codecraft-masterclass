## 📌 Summary
Understanding Rust as an expression-oriented language. Defining functions, explicit type annotations, statements vs expressions (the semicolon rule), block evaluation, and early returns.

## 🎯 Key Takeaways
- Rust is fundamentally expression-oriented; omitting the final semicolon returns the expression value
- Function parameters strictly require type annotations to serve as clear, compiler-enforced contracts
- Code blocks { } evaluate directly to the value of their final trailing expression
