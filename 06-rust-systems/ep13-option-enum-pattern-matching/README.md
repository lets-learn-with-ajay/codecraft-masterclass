## 📌 Summary
Never suffer a NullPointerException again. How Option<T> (Some/None) encodes optional values into the type system, match, if let shorthand, and modern Rust let-else guards.

## 🎯 Key Takeaways
- Option<T> replaces null by forcing explicit compile-time handling of missing values
- if let provides concise handling when you only care about a single variant (e.g. Some)
- let else allows early return guard clauses, extracting inner values or diverging immediately
