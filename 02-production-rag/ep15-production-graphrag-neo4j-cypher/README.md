## 📌 Summary
Grounding retrieval in structured knowledge. Modeling extracted entity-relationship graphs in Neo4j, generating Cypher queries with LLMs, and combining graph traversal with vector similarity.

## 🎯 Key Takeaways
- Graph databases model complex multi-hop entity relationships that vector search misses entirely
- Few-shot prompted LLMs translate natural language queries into deterministic Cypher traversals
- Combining graph neighbourhood subgraphs with vector text chunks provides bulletproof context
