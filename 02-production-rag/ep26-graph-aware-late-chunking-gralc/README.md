## 📌 Summary
State-of-the-art retrieval architecture. Combining document structural graphs (headers, sections, parent-child links) with late-chunking token embeddings for holistic technical manual retrieval.

## 🎯 Key Takeaways
- Fuses topological document graph structures with contextual transformer token representations
- Guarantees that section context and parent chapter definitions are embedded into leaf chunks
- Significantly outperforms traditional chunking on complex engineering manuals and legal codes
