## 📌 Summary
Combining dense semantic vectors with sparse BM25 keyword matching using Reciprocal Rank Fusion (RRF).

## 🎯 Key Takeaways
- Dense embeddings often miss exact IDs, product codes, abbreviations, and domain jargon.
- BM25 provides exact keyword precision and term frequency weighting.
- RRF mathematically fuses rankings from multiple retrieval algorithms without requiring score normalization.
