## 📌 Summary
Extracting structured (Subject, Predicate, Object) triplets from unstructured text to build queryable knowledge graphs.

## 🎯 Key Takeaways
- Unstructured text contains rich implicit relationship graphs that simple vector embeddings flatten.
- LLM extraction prompts extract normalized entities and labeled relationship edges.
- Graph databases like Neo4j index relationships as first-class citizens for multi-hop graph queries.
