## 📌 Summary
Answering global summarization and multi-hop questions using hierarchical Leiden community clustering algorithms on knowledge graphs.

## 🎯 Key Takeaways
- Vector search fails when user questions span multiple disconnected documents or need global corpus-level summaries.
- Community detection algorithms (Leiden/Louvain) group related entities into hierarchical topic clusters.
- Generates comprehensive global summaries across millions of documents without exceeding context windows.
