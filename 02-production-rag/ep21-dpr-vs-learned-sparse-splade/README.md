## 📌 Summary
Beyond classical BM25. Implementing modern learned sparse representations with SPLADE v3 and BM42, expanding query terms with neural weights, and combining with dense embeddings.

## 🎯 Key Takeaways
- Classical BM25 relies strictly on exact word matches without vocabulary expansion
- SPLADE uses BERT masked language modeling to dynamically inject related vocabulary terms with weights
- Delivers the exact keyword precision of sparse search with the semantic awareness of dense vectors
