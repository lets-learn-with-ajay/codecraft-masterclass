## 📌 Summary
Answering global holistic questions across corpora. Recursively clustering text chunks using Gaussian Mixture Models, generating multi-layer abstractive summaries, and querying across all tree tiers.

## 🎯 Key Takeaways
- Standard vector search fails on corpus-wide summarization questions ('What are the major themes?')
- RAPTOR builds a multi-level tree of recursive summaries from leaf chunks up to root summaries
- Retrieves context across multiple levels of abstraction to synthesize comprehensive answers
