## 📌 Summary
Overcoming poorly framed user questions using Hypothetical Document Embeddings (HyDE) and query decomposition techniques.

## 🎯 Key Takeaways
- Users rarely write optimal search queries for vector retrieval.
- HyDE generates a hypothetical answer first, then embeds that synthetic document to match real knowledge base articles.
- Sub-question decomposition breaks complex, multi-part queries into parallel sub-searches.
