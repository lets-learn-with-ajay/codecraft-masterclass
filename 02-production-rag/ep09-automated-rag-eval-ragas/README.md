## 📌 Summary
Setting up automated CI/CD evaluation pipelines for your RAG system using Ragas and the RAG Triad.

## 🎯 Key Takeaways
- Never deploy RAG changes or prompt updates without automated precision and ground-truth metrics.
- Faithfulness measures whether generated answers are strictly grounded in retrieved context chunks.
- Context precision measures if the top retrieved chunks were actually relevant to answering the query.
