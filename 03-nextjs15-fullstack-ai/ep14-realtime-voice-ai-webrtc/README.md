## 📌 Summary
Sub-500ms conversational voice assistants. Setting up low-latency bidirectional audio streaming using WebRTC in Next.js 15, handling client microphone input, and seamless audio interruptions.

## 🎯 Key Takeaways
- WebRTC eliminates HTTP round-trip latency, delivering sub-500ms voice conversational turns
- Client-side Voice Activity Detection (VAD) detects user speech and interrupts ongoing audio playback instantly
- Bridges real-time voice conversations with background database updates and tool executions
