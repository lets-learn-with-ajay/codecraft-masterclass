## 📌 Summary
Full-stack client-side document processing. Drag-and-drop file upload zones, extracting text directly on the edge, semantic vector querying, and rendering interactive popover citations in streaming chat.

## 🎯 Key Takeaways
- Process and chunk user-uploaded documents at the edge without heavy server file uploads
- Embed citations as custom markdown spans ([1]) linked to extracted source metadata
- Clicking citations opens interactive popovers displaying the exact quoted document excerpt
