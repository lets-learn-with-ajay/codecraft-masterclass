## 📌 Summary
Enterprise cost and usage observability. Logging streaming token usage, TTFT, and API costs to ClickHouse, visualizing p95 latency and spend per organization using Shadcn charts and Tremor.

## 🎯 Key Takeaways
- Stream token consumption events asynchronously to ClickHouse without blocking client responses
- Calculate real-time p50, p90, and p99 latency percentiles across different LLM providers
- Provide organizations with transparent cost tracking and automated budget threshold alerts
