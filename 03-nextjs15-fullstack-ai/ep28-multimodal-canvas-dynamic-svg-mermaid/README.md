## 📌 Summary
Visual AI generation. Instructing models to output interactive SVGs, Mermaid architecture flows, and Excalidraw-style mindmaps, with live pan, zoom, and direct client-side node editing.

## 🎯 Key Takeaways
- Prompt models to generate strict XML-valid SVG markup with CSS animations and responsive viewboxes
- Render interactive Mermaid.js diagrams with zoom/pan controls and clickable node triggers
- Allow users to click any diagram node and prompt the AI to expand or modify that specific component
