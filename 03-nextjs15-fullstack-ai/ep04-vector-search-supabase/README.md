## 📌 Summary
Implementing semantic search directly inside PostgreSQL using `pgvector` and Next.js 15 Server Actions.

## 🎯 Key Takeaways
- `pgvector` keeps relational user data and vector embeddings consolidated in one database.
- Server Actions securely query the database without exposing sensitive API keys to the browser.
- HNSW indexes provide sub-10ms similarity searches across millions of vector rows.
