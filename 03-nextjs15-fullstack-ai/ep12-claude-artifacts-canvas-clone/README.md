## 📌 Summary
Creating an interactive dual-pane workspace. Building a side-by-side chat and canvas UI with React 19, allowing LLMs to create, render, and live-update interactive code sandboxes and documents.

## 🎯 Key Takeaways
- Implement a split-view layout with dynamic resizing and synchronized conversation state
- Render live React components, SVG diagrams, and markdown documents inside sandboxed iframes
- Enables bidirectional communication: users can edit canvas code directly and prompt LLMs to revise
