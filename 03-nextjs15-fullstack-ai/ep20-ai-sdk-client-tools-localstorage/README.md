## 📌 Summary
Connecting LLMs to client hardware. Injecting browser geolocation, window dimensions, and local preferences into AI tools, with automatic synchronization to localStorage.

## 🎯 Key Takeaways
- Define client-side tools that execute directly in the browser without server round trips
- Access Web APIs (navigator.geolocation, screen dimensions, local notifications) safely
- Persist client UI settings and offline draft messages automatically to localStorage
