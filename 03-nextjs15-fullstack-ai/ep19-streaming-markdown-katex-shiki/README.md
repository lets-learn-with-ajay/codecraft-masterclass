## 📌 Summary
Flicker-free streaming UI engineering. Rendering streamed markdown chunks with react-markdown, beautiful code blocks with Shiki syntax highlighting, and mathematical formulas with KaTeX.

## 🎯 Key Takeaways
- Unclosed code blocks and math delimiters during token streaming cause severe layout thrashing
- Implement custom streaming parsers that balance incomplete markdown fences dynamically
- Shiki provides VS Code-grade dual-theme (dark/light) syntax highlighting without client bundle bloat
