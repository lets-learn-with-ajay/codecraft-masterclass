## 📌 Summary
Setting up low-latency token streaming with `streamText`, Server-Sent Events (SSE), and the React `useChat` hook in Next.js 15.

## 🎯 Key Takeaways
- App Router Route Handlers stream Server-Sent Events directly to the browser.
- The `useChat` hook manages message state, abort controllers, and optimistic UI updates seamlessly.
- Zero layout shifts occur during streaming token arrival with fine-grained DOM updates.
