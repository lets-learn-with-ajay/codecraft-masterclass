## 📌 Summary
Safe arbitrary code execution. Running untrusted LLM-generated Python and JavaScript code inside isolated micro-VM sandboxes, streaming console stdout/stderr, and rendering generated charts.

## 🎯 Key Takeaways
- Never execute LLM-generated code directly in the host server runtime
- Spin up isolated, ephemeral micro-VM sandboxes with restricted network access and resource quotas
- Stream real-time terminal output and capture generated matplotlib/plotly charts for UI display
